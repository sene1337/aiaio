# Demand signals — last30days social scan, 2026-07-15

What indie-game demand looked like across Reddit/X/TikTok/HN/etc. for the window
2026-06-15 → 2026-07-15, and what (little) AIAIO should take from it. Compiled from a
/last30days engine run (183 items, 11 sources); raw evidence saved at
`~/Documents/Last30Days/game-ideas-people-are-asking-to-get-built-and-features-players-are-begging-for-raw-v3.md`.

Standing directive at time of writing: **core polish only, big ideas parked.** This note
exists so the release/beta-2 planning can pick it up later — it is not a request to build
anything now.

---

## The one takeaway for AIAIO

**The clip loop is the demand engine — treat pre-share review UI + one-tap clip export as
the growth gate, not a safety chore.**

Evidence pattern: indie demand this window was manufactured pre-launch through clippable
moments, not store pages.

- Dear Passengers (Flexus, co-op "worst airline" friendslop): ~500K wishlists/day off a
  trailer of its funniest 10 seconds; reaction clips at 2.5M views for a game with no demo
  and no date. (kotaku.com/dear-passengers…, dev.ua/en/news/dear-passengers-1784100084)
- "i'm actually begging someone to steal this idea" TikTok (@emmatheabomination): 1.9M
  views / 261K likes for a horror *concept pitch* — the clip generated the demand, the game
  doesn't exist.
- Counter-signal: hamunohamster's Steam-ultimatum reel — the clippable mechanic IS the game
  ("that's what players clip, that's what goes viral") and also the thing that draws
  platform/policy risk.

AIAIO mapping: the clippable moment already exists — THE OBSERVER roasting your real
session, word-splash impacts, awards of shame. Beta-2's pre-share review UI is the
prerequisite (real session data in clips is our version of the platform-risk pattern;
redaction must gate every export). The clip should feature the Observer: personality is
what travels.

## Validation (no action)

Wish-posts this window favored novel containers and inversions — "why doesn't this exist"
mashups (multiplayer Fire Emblem, football Uma Musume, survive-as-indie-cafe sims).
Real-session-as-level sits squarely in that shape. The bet is right; nothing to change.

## Considered and rejected (with reasons)

- **Comments-decide-the-game launch format** (fromzerogamedev: top comment becomes next
  update). Zero code and proven as content, but it structurally invites feature pile-on —
  the opposite of the core-first directive. Revisit only at community-release time, if ever.
- **Friendslop co-op / session raids with friends.** Biggest demand pattern in the scan,
  worst fit: a whole new system for a game whose premise is *your* session, *your* amnesia.
  If it ever resurfaces it gets a `docs/PARKED-` file next to task dives.
- **Player-voted patches / governance** (LoL Classic's OSRS-style council, 745-pt
  r/pcgaming thread). Feature players beg for in decade-old live-service games; meaningless
  for a pre-release single-dev project.
